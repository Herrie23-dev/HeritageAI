FREQUENTLY ASKED QUESTIONS

Questions?

Can I use my own PowerPoint?

Yes. HeritageAI is designed to let you select the PowerPoint presentation you want to control.

Do I need Python installed?

No. The packaged HeritageAI Windows application is designed to run without requiring Python.

Who is HeritageAI for?

Students, lecturers, trainers, speakers and professionals who use PowerPoint presentations.

What voice commands can I use?

You can start a presentation, move to the next or previous slide, jump to a specific slide and stop presentation control using the supported command patterns listed on this page.

Can I suggest a feature?

Absolutely. HeritageAI is still growing, and user feedback will help shape what comes next. You can connect with the creator on LinkedIn.

Is HeritageAI available for Mac?

The current release linked here is for Windows.
